# Retrofit R0: AHN-GDN-3B ported into the pilot engine (4 Nov 2026)

## Port
* **Code:** `pilot/ahn_port.py` plus `pilot/gdn.py`, a pure-PyTorch gated delta rule with per-token outputs that equals the per-token loop to 1e-10 (`tests/test_pilot_gdn.py`). AHN's fla fork is not used in our environment.
* **Semantics** (from AHN's `qwen2_ahn.py` and `gated_deltanet.py`):
  * attention sees the 128 sinks plus a per-token window (t − W, t];
  * the memory holds tokens from position 128 to t − W, using post-RoPE q and k (L2-normalized inside the delta rule, scale d^-1/2) with k and v repeated to all 16 heads;
  * beta and alpha come from the written token's normalized input; the output is a swish-gated RMSNorm on the query's input, then a per-head o_proj, added before the layer's o_proj.
* **Equivalence** against AHN's own code (`pilot/ref_ahn.py`, AHN's environment, merged model, prefill path, bf16), on 4,096 tokens of the fact stream with W 1024 and 128 sinks:

| variant | mean \|ΔNLL\| | beyond window | corr |
|---|---|---|---|
| **our port** | **0.051** | **0.053** | 0.99956 |
| port with memory shifted one token | 0.052 | 0.054 | 0.99959 |
| port without the output gate | 0.140 | 0.176 | 0.99650 |
| window only | 0.150 | 0.193 | 0.99603 |
| full attention | 0.285 | 0.381 | 0.96620 |

A float32 reference is impossible: AHN's flex-attention and Triton kernels need 148 KB of shared memory against a 101 KB limit. The residual 0.05 matches the bf16 noise measured before (0.077 on 0.5B). A one-token alignment error cannot be resolved at this precision and does not change behaviour.

## G0′ and baselines on Qwen2.5-3B
Validation seeds 0–2 × exc {0.2, 0.5}; W 1024, 128 sinks, per-token window for every arm (`pilot_20261104_r0_g0_3b.jsonl`).

| arm | overall | rule | exc beyond W | retest rule | stream NLL |
|---|---|---|---|---|---|
| full attention | 0.839 | 0.783 | 0.842 | | 2.820 |
| window only | 0.180 | 0.449 | 0.005 | | 3.019 |
| window + 512 pairs (AHN's bytes) | 0.259 | 0.638 | 0.059 | | 2.949 |
| released AHN-GDN | 0.174 | 0.420 | 0.005 | 0.000 | 2.993 |

* **G0′:** full attention reaches 0.839, below the 0.90 bar (1.5B reached 0.88), mostly because recurring facts with drift come out lower.
* **Released AHN** recalls no exact fact from its state: exceptions beyond W are 0.005, the same as window only. It lowers stream NLL a little, but less than spending its bytes on a bigger window.

## Refits for 3B (validation seeds; `r0_fit_3b.log`)
* **Landmark selector:** held-out precision 0.71–0.77, keeping 0.69–0.76 of fact tokens.
* **Kappa reuse AUC** (held-out): 0.54–0.75, weaker than on 1.5B (0.78).

## Implication for R1 and R2
R1 assumed AHN's trained read path could retrieve facts from a state written by replay. The released AHN cannot retrieve exact facts even from its own arrival-order writes, so R1 as planned would very likely show retest ≈ 0 for every write policy. It would test nothing.

**Proposed change:** go to an R2 gate first. KL-fine-tune the `ahn` arm alone on the fact streams and check whether exact far-exception or retest recall emerges at all, before comparing write policies.
